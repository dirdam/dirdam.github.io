# Legacy Squadro tools

Archived copies of the old Squadro helper pages from the former
`dirdam.github.io` site (game replay, replay loader, board setter). They are
**not built into the site, not deployed, and not linked from anywhere** —
they are only kept here for the record. Squadro can be played and replayed at
https://squadro.app.

Layout mirrors the original site so the relative paths still resolve if the
files are ever opened locally (`games/…`, `assets/…`, `images/…`).
